# 游戏内验收清单

以下项目尚待实机验收，不能以编译成功或保存拦截测试代替。

1. 在已有未完成冒险的测试配置中记录 `current_run.save`、进度文件的路径和 SHA-256。保留备份。
2. 安装并启用 Mod，确认主菜单出现靶场入口，原有继续游戏入口仍然存在。
3. 选铁甲战士、基础攻击卡和普通怪物，进入战斗；确认直接到战斗，无需选路线或事件。
4. 确认牌组为角色完整初始卡组加一张所选卡牌（若所选卡也是初始卡，应额外多一张），能量符合设置，可以正常出牌、结束回合，敌人正常行动。勾选升级时，只有额外添加的测试卡升级。
5. 在玩家行动阶段追加卡牌；在敌人回合和手牌满时验证操作被拒绝。
6. 连续重置至少三次，确认生命、卡牌、怪物、能量及随机种子恢复初始条件，且不出现 “Make sure to reset the combat before setting up a new one.”。
7. 杀死敌人后重置；让角色死亡后重置；确认均可再次战斗。死亡结算页应显示正常死亡说明（原版遭遇使用原版说明，独立靶场使用练习结束提示），不应出现要求联系 MegaCrit 程序员的排错文案；主菜单按钮应正常返回。
8. 从靶场工具栏退出，选择另一组角色/卡牌/怪物重新进入，重复至少三次；另测原版暂停菜单的保存退出。
9. 检查原有冒险和进度文件哈希不变；继续原有冒险，确认加载内容与测试前一致。
10. 返回普通冒险，确认普通保存正常；检查靶场拦截没有持续生效。
11. 分别验证其他角色的专属机制、升级卡、X 费卡、生成卡、能力卡和状态牌。
12. 对首领、召唤型、依赖同伴或专属场景的怪物逐个记录兼容性；未验证前不宣称完全兼容。
13. 打开靶场卡牌总览，检查角色卡池、类型、稀有度、费用、文字搜索、排序、升级预览与原版一致。尚未发现的卡也应可查看和搜索；点击卡牌、关闭详情、确认后，设置页应显示选择的卡和升级状态。
14. 打开靶场怪物图鉴，确认地图分组、怪物介绍、招式按钮和动画预览沿用原版。选择未解锁地图中的怪物并确认，应回到设置页。检查多怪物布局和特殊遭遇布局。
15. 在较小窗口中滚动设置面板，确认开始和返回按钮始终可以滚动到。
16. 选择异蛙寄生虫，击杀本体后应出现四只扭动虫；能继续正常出牌、结束回合，并在击杀二阶段后结束战斗。检查日志不再出现精英房二阶段音乐切换异常。
17. 在死亡结算动画中、动画完成后分别使用「重置同一测试」，重复至少三次，确认直接进入新战斗，没有中途重建主菜单或闪退；之后从工具栏退出，确认原版菜单及设置可正常打开。
18. 分别测试其他地图的精英、首领和召唤物，确认背景及音乐使用原版遭遇对应的地图；同一配置重置后，开场敌人数量和站位一致。
19. 击杀异蛙及四只扭动虫后，应出现「测试胜利」面板，能从面板重置或返回菜单；战斗左侧不应继续显示可正常出牌的状态。
20. 在敌人回合、手牌已满、胜利和死亡界面确认加牌按钮禁用；战斗结束前后快速点击也不应写入操作失败日志。
21. 种子留空连续开始多次新测试，检查显示的种子和抽牌过程会变化；对同一次测试重置，检查种子和起手顺序一致。输入相同显式种子和配置也应复现。
22. 主菜单靶场入口应在多人模式和时间线之间；字体、悬停、焦点箭头与原版按钮一致。用鼠标及键盘上下切换，并检查有继续游戏入口时的布局。
23. 设置页打开期间按主菜单快捷键，确认不触发背景操作。进入两个选择页及卡牌详情，再逐层返回；确认返回只关闭当前页面。连续打开关闭三次后，主菜单快捷键恢复正常。
24. 卡牌搜索输入后立即返回，重复打开关闭并切换到怪物页，确认没有延迟更新已关闭页面的异常。图鉴预览期间返回、开始战斗或退出菜单，确认预览及快捷键资源正确清理。
25. 在靶场查看未解锁内容后，打开原版百科，确认发现状态、筛选、预览和返回行为保持原样，存档未变化。重启游戏再次确认。

排查时在游戏日志中搜索 `[SpireRange]`。特别检查初始化、资源预加载、卡牌升级以及切换场景时的异常。
