# 游戏内验收清单

以下项目尚待实机验收，不能以编译成功或保存拦截测试代替。

原版选人页迁移专项：

- 从靶场打开选人页后直接返回，再进入普通单人模式；确认普通「启程」仍然正常开始冒险。反向操作也检查一次，重复三次。
- 从靶场选人并确认时，只进入设置页，不开始普通冒险，不出现接受教程提示。靶场选人页不显示进阶难度面板；普通单人模式仍正常显示。
- 先选好卡牌、升级状态、怪物、能量和显式种子，再点击「更换角色」。确认默认选中当前角色，取消时全部配置不变；确认另一角色后仅角色改变。重新打开卡牌总览时默认筛选新角色卡池。
- 检查角色解锁规则沿用原版；随机角色可用时确认它，设置页应显示实际角色，入场后初始卡组和遗物应与该角色一致，重置保持同一角色。
- 在原版选人页用鼠标、键盘和手柄分别确认及返回；设置页、图鉴页和选人页之间反复切换，检查焦点、快捷键、背景音乐及界面遮挡。选人页和设置页截图尚需实机更新。

1. 在已有未完成冒险的测试配置中记录 `current_run.save`、进度文件的路径和 SHA-256。保留备份。
2. 安装并启用 Mod，确认主菜单出现靶场入口，原有继续游戏入口仍然存在。
3. 点击靶场后应打开原版角色选择页，包含角色立绘、介绍和初始遗物；选择铁甲战士并确认后应进入靶场设置页，角色不再是下拉框。选基础攻击卡和普通怪物，进入战斗；确认直接到战斗，无需选路线或事件。
4. 确认牌组为角色完整初始卡组加一张所选卡牌（若所选卡也是初始卡，应额外多一张），能量符合设置，可以正常出牌、结束回合，敌人正常行动。勾选升级时，只有额外添加的测试卡升级。
5. 确认战斗左侧不再出现工具窗或加牌按钮；顶部蓝色栏内显示靶场标识、种子，字体颜色及描边与原版计时器一致。
6. 连续重置至少三次，确认生命、卡牌、怪物、能量及随机种子恢复初始条件，且不出现 “Make sure to reset the combat before setting up a new one.”。
7. 杀死敌人后重置；让角色死亡后按 Esc 再重置；确认均可再次战斗。死亡结算页应显示正常死亡说明（原版遭遇使用原版说明，独立靶场使用练习结束提示），不应出现要求联系 MegaCrit 程序员的排错文案；主菜单按钮应正常返回。
8. 从暂停菜单「退出靶场」返回，选择另一组角色/卡牌/怪物重新进入，重复至少三次；确认不会保存靶场，也不会影响原有冒险。
9. 检查原有冒险和进度文件哈希不变；继续原有冒险，确认加载内容与测试前一致。
10. 返回普通冒险，确认普通保存正常；检查靶场拦截没有持续生效。
11. 分别验证其他角色的专属机制、升级卡、X 费卡、生成卡、能力卡和状态牌。
12. 对首领、召唤型、依赖同伴或专属场景的怪物逐个记录兼容性；未验证前不宣称完全兼容。
13. 打开靶场卡牌总览，检查角色卡池、类型、稀有度、费用、文字搜索、排序、升级预览与原版一致。尚未发现的卡也应可查看和搜索；在详情中直接确认应回到设置页。左右翻页后再确认，应选择最后展示的卡，而非最初点击的卡；勾选/取消查看升级后分别确认，检查设置页标记及入场卡牌升级状态。设置页不应再有升级选框。
14. 打开靶场怪物图鉴，确认地图分组、怪物介绍、招式按钮和动画预览沿用原版。确认按钮应在左下角，且不遮住返回按钮或右侧列表。选择未解锁地图中的怪物并确认，应回到设置页。检查多怪物布局和特殊遭遇布局。
15. 在较小窗口中滚动设置面板，确认开始和返回按钮始终可以滚动到；每回合基础能量的输入框应紧跟标签，缩放时不应靠到最右侧。
16. 选择异蛙寄生虫，击杀本体后应出现四只扭动虫；能继续正常出牌、结束回合，并在击杀二阶段后结束战斗。检查日志不再出现精英房二阶段音乐切换异常。
17. 在死亡结算动画中、动画完成后分别打开暂停菜单；可操作时使用「重置靶场」，重复至少三次，确认直接进入新战斗，没有中途重建主菜单或闪退；之后使用「退出靶场」，确认原版菜单及设置可正常打开。
18. 分别测试其他地图的精英、首领和召唤物，确认背景及音乐使用原版遭遇对应的地图；同一配置重置后，开场敌人数量和站位一致。
19. 击杀异蛙及四只扭动虫后，应出现「测试胜利」面板，能从面板重置或返回菜单；打开暂停菜单和设置时，胜利面板不应盖住原版菜单。
20. 原版风格的暂停菜单应按顺序显示继续、设置、百科大全、重置靶场、退出靶场（百科未解锁时不显示该项）；不应出现「放弃」。鼠标及键盘焦点均可操作新增项；忙碌期间重置/退出禁用；连续点击不应启动两次重置。返回普通冒险后，原版保存并退出和多人断开连接不应被替换。
21. 种子留空连续开始多次新测试，检查顶部显示的种子和抽牌过程会变化；对同一次测试重置，检查种子和起手顺序一致。输入相同显式种子和配置也应复现。切换计时器显示、改变窗口大小，检查种子与生命/金币/药水/楼层及右侧按钮不重叠；长种子省略时悬停可查看完整值。
22. 主菜单靶场入口应在多人模式和时间线之间；字体、悬停、焦点箭头与原版按钮一致。用鼠标及键盘上下切换，并检查有继续游戏入口时的布局。
23. 设置页打开期间按主菜单快捷键，确认不触发背景操作。进入两个选择页及卡牌详情，再逐层返回；确认返回只关闭当前页面。连续打开关闭三次后，主菜单快捷键恢复正常。
24. 卡牌搜索输入后立即返回，重复打开关闭并切换到怪物页，确认没有延迟更新已关闭页面的异常。图鉴预览期间返回、开始战斗或退出菜单，确认预览及快捷键资源正确清理。
25. 在靶场查看未解锁内容后，打开原版百科，确认发现状态、筛选、预览和返回行为保持原样，存档未变化。重启游戏再次确认。
26. 单独选择扭动虫开始，确认使用原版异蛙寄生虫场景和扭动虫站位、正常抽牌并获得能量；怪物首回合显示出生眩晕，随后正常交替攻击与强化。重置三次不应出现 `No valid next state found`。
27. 对开场任务已经抛出异常的靶场，检查顶部错误提示及悬停原因；Esc 中重置/退出应恢复可用，并正确清理残留 `IsStarting`。正常尚未完成的开场任务仍应禁用这些操作；其他战斗或已退出的旧任务异常不应改变当前靶场状态。

排查时在游戏日志中搜索 `[SpireRange]`。特别检查初始化、资源预加载、卡牌升级以及切换场景时的异常。
