# Spire Range / 杀戮尖塔 2 靶场

一个为《杀戮尖塔 2》添加独立训练战斗的 Mod。从主菜单进入靶场，选择角色、卡牌和怪物，即可测试卡牌效果，无需开始正常冒险或选择路线。

## 安装

1. 关闭游戏。
2. 将安装包中的 `SpireRange` 文件夹放入游戏安装目录的 `mods` 文件夹。
3. 启动游戏，在 Mod 设置中启用「靶场 / Spire Range」；如果游戏提示重启，重启后生效。

安装后的文件结构：

```text
Slay the Spire 2/
└─ mods/
   └─ SpireRange/
      ├─ SpireRange.dll
      └─ SpireRange.json
```

更新时关闭游戏，替换上述两个文件即可。支持的游戏版本：**v0.107.1**。

## 使用

1. 点击主菜单左上角的「靶场 / Practice Range」。
2. 选择角色、测试卡牌和目标怪物。卡牌和怪物均可通过名称或 ID 搜索。
3. 按需选择升级版卡牌、调整每回合基础能量和随机种子。
4. 点击「开始测试 / Start」进入战斗。

测试牌组由**角色初始卡组 + 1 张所选卡牌**组成，保留角色初始遗物和专属机制。卡牌按正常战斗规则洗牌和抽取；若想立即测试，可以使用战斗中的「再加一张测试卡」。升级选项仅作用于额外添加的测试卡牌。

战斗左侧提供以下操作：

| 操作 | 效果 |
| --- | --- |
| 再加一张测试卡 / Add card | 将一张所选卡牌加入手牌，升级状态与设置一致 |
| 重置同一测试 / Reset | 按相同角色、卡牌、怪物和随机种子重新开始战斗 |
| 退出靶场 / Exit | 返回主菜单，可重新选择另一组测试条件 |

请在当前动画和卡牌效果结束后重置或退出。战斗结束后，使用靶场工具栏重置或退出。

## 常见问题

**没有看到靶场入口？**

确认 `SpireRange.dll` 和 `SpireRange.json` 在同一个 `mods/SpireRange` 文件夹内，并已在游戏中启用 Mod。更新后需要重新启动游戏。

**所选卡牌没有出现在起手手牌里？**

它已加入牌组，会随正常洗牌和抽牌出现。点击「再加一张测试卡」可以直接将其加入手牌；手牌已满或当前不可出牌时不能添加。

**靶场会影响正常冒险吗？**

靶场使用独立的临时战斗，不保存本局进度，也不更新正常冒险的战斗进度。

**为什么某些怪物表现不同？**

靶场生成单个怪物。依赖同伴、阶段切换或专属场景的怪物，可能无法完整重现原生遭遇的行为。目前只支持单人训练。

**如何反馈问题？**

请提供游戏版本、所选角色/卡牌/怪物、操作步骤及报错截图。游戏日志中的 `[SpireRange]` 记录有助于定位问题。
