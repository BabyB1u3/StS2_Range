# 靶场 / Spire Range

《杀戮尖塔 2》卡牌测试 Mod。选择角色、卡牌和怪物，直接开始练习战斗，无需从头打一局冒险。

![靶场战斗：铁甲战士对战异蛙寄生虫](docs/images/combat.png)

## 功能

- 自选角色、多张测试卡牌和目标怪物，支持重复加牌，每张可单独选择升级版。
- 卡牌支持分类筛选和搜索，怪物可按地图浏览。
- 自定义每回合基础能量，使用随机种子或指定种子。
- 一键重置当前战斗，保留配置和种子。

## 安装

适用游戏版本：**v0.107.1**。

1. 关闭游戏。
2. 将安装包中的 `SpireRange` 文件夹放入游戏安装目录的 `mods` 文件夹，没有则新建。
3. 启动游戏并启用「靶场 / Spire Range」。如果提示重启，重启游戏后生效。

确认文件位置如下：

```text
Slay the Spire 2/
└─ mods/
   └─ SpireRange/
      ├─ SpireRange.dll
      └─ SpireRange.json
```

更新时，关闭游戏并替换这两个文件。

## 开始练习

在主菜单点击「靶场」。

![主菜单中的靶场入口](docs/images/main-menu.png)

先在原版选人界面选择角色并确认，再打开卡牌总览。在卡牌详情中点击「加入测试卡组」，可继续浏览并添加其他卡牌，同一卡牌也能重复加入；添加前勾选「查看升级」，即可加入升级版。选好后点击「完成选择」返回设置页，可以逐张移除已选卡牌。

打开怪物图鉴并确认目标，设置好基础能量后，点击「开始测试」。种子可留空随机，也可填写指定值。设置页可点击「更换角色」重新选人，已填的其他配置会保留。

![靶场设置：选择角色、卡牌、怪物、能量和种子](docs/images/setup.png)

每场战斗使用**角色初始卡组 + 全部已选测试卡牌**，保留初始遗物。至少选择一张测试卡牌；每次添加都会产生一份独立副本。测试卡牌参与正常洗牌和抽牌，不保证出现在起手中。重置会保留全部卡牌及各自的升级状态。

战斗中按 **Esc**，选择「重置靶场」重新开始，或「退出靶场」返回主菜单。重置会保留本次配置和种子；想换一组随机结果，可返回主菜单，种子留空再开始。

胜利后，也可以直接在结算面板重置或退出。

![战斗胜利后的重置和退出选项](docs/images/victory.png)

## 兼容说明

- 目前支持单人练习，不保存本局冒险进度。
- 部分依赖同伴或特殊遭遇的怪物，单独测试时可能与正常冒险中的表现不同。
