# Spire Range / 杀戮尖塔 2 靶场

为《杀戮尖塔 2》添加独立的训练战斗入口。当前为 **0.1.0 实验原型**，针对本地 **v0.107.1 / .NET 9** 开发。

## 当前功能

- 主菜单左上角的「靶场 / Practice Range」入口。
- 选择原版角色、卡牌和一个怪物，支持名称或 ID 搜索。
- 选择升级版卡牌、每回合基础能量、固定随机种子。
- 用五张所选卡牌组成测试牌组，保留角色的初始遗物和机制。
- 使用游戏原有出牌、伤害、状态、敌人回合逻辑。
- 战斗左侧可追加测试卡、重建相同条件的战斗、退出。
- 临时局设置 `shouldSave: false` 并关闭战斗录像，额外拦截原版战斗结束时的保存、进度更新及当前冒险存档删除操作；拦截仅在靶场会话内生效。
- 拦截靶场中的地图选路与战后继续，防止训练意外转入正常冒险；结束战斗后使用靶场工具栏重置或退出。

## 开发与构建

需要 .NET 9 SDK，以及合法安装的游戏。无需 BaseLib 或 Godot 编辑器；首版使用代码创建 Godot 控件，没有额外素材包。

```powershell
.\scripts\build.ps1 -Test
```

非默认安装路径：

```powershell
.\scripts\build.ps1 -GameDir 'E:\SteamLibrary\steamapps\common\Slay the Spire 2' -Test
```

输出为 `artifacts/SpireRange/SpireRange.dll` 和 `SpireRange.json`。构建脚本不会自动安装或启动游戏。

将整个 `SpireRange` 输出文件夹复制到游戏的 `mods` 目录，然后启动游戏并在游戏内启用。安装或更新时应先关闭游戏。

`tests/SpireRange.Smoke` 在独立进程中，将真实 Harmony 补丁应用于本地游戏的 `SaveManager`，验证训练时拦截写入、普通游戏时放行；不会构造保存系统或访问玩家存档。此测试不覆盖 Godot 界面和实际战斗。

## 验证状态与已知限制

- 已通过本机 v0.107.1 的 Release 编译及保存隔离集成测试；尚未完成游戏内界面和战斗验收。
- 单怪物模式不保留其原生遭遇的队伍布局、专属场景和遭遇钩子；依赖同伴、阶段切换或专属场景的怪物可能无法正常工作。
- 初版为单人训练，不支持联机、不提供任意遗物或状态编辑。
- 尚未验证其他游戏版本及与其他 Mod 的兼容性。
- 暂未做专用视觉设计、手柄导航和低分辨率适配。

人工验收步骤见 [docs/TESTING.md](docs/TESTING.md)。

## 项目约定

游戏程序集、反编译文件、工具缓存和构建产物不提交到 Git。项目直接引用本机游戏文件，不包含游戏代码或素材。

开发参考：[社区 Mod 模板和教程](https://github.com/Alchyr/ModTemplate-StS2/wiki)、安装目录中的 `sts2.xml`，以及用 ILSpy 检查当前版本的程序集。
