# Spire Range / 杀戮尖塔 2 靶场

一个为《杀戮尖塔 2》添加独立训练战斗的 Mod。从主菜单进入靶场，选择角色、卡牌和怪物，即可测试卡牌效果，无需开始正常冒险或选择路线。

## 安装

1. 关闭游戏。
2. 将安装包中的 `SpireRange` 文件夹放入游戏安装目录的 `mods` 文件夹。
3. 启动游戏，在 Mod 设置中启用「靶场 / Spire Range」；如果游戏提示重启，重启后生效。

安装后的文件结构：

```text
Slay the Spire 2/
└─ mods/
   └─ SpireRange/
      ├─ SpireRange.dll
      └─ SpireRange.json
```

更新时关闭游戏，替换上述两个文件即可。支持的游戏版本：**v0.107.1**。

## 使用

1. 点击主菜单中「多人模式」和「时间线」之间的「靶场 / Practice Range」。
2. 选择角色，点击「打开卡牌总览」，使用角色、类型、稀有度、费用和搜索筛选卡牌。点击卡牌进入详情，可左右切换卡牌，并直接点击「使用这张卡牌」确认。勾选详情中的「查看升级」后，确认选择的就是升级版卡牌。
3. 点击「打开怪物图鉴」，按地图浏览怪物，查看介绍和招式预览，点击左下角的「使用这个怪物」确认。
4. 调整每回合基础能量。种子留空时，每次新测试随机生成；填写种子可复现测试。
5. 点击「开始测试」进入战斗。

测试牌组由**角色初始卡组 + 1 张所选卡牌**组成，保留角色初始遗物和专属机制。卡牌按正常战斗规则洗牌和抽取。详情中的升级选择仅作用于额外添加的测试卡牌，设置页会显示其升级状态。

靶场的卡牌总览和怪物图鉴沿用游戏百科的界面，可选择尚未解锁的卡牌及怪物，不改变原版百科的解锁状态。使用页面的返回按钮或返回快捷键回到靶场设置。

战斗中按 **Esc** 打开暂停菜单：

| 操作 | 效果 |
| --- | --- |
| 重置测试 | 按相同角色、卡牌、怪物和随机种子重新开始战斗；位于「放弃」下方 |
| 退出靶场 | 返回主菜单，可重新选择另一组测试条件；替代靶场中的「保存并退出」 |

请在当前动画和卡牌效果结束后重置或退出；暂时不能操作时，对应按钮会禁用。普通冒险的暂停菜单保持原样。

胜利后会显示测试完成面板，可直接重置或返回主菜单。死亡后也可按 Esc 使用靶场暂停菜单。

靶场标识和本次种子显示在战斗顶部蓝色信息栏中。点击「重置测试」会保留种子和配置；返回主菜单、种子留空再开始，才会生成新的随机测试。随机种子控制游戏的洗牌等随机过程，因此同一配置和种子会复现相同抽牌顺序；随机测试也可能碰巧抽到相似手牌。

## 常见问题

**没有看到靶场入口？**

确认 `SpireRange.dll` 和 `SpireRange.json` 在同一个 `mods/SpireRange` 文件夹内，并已在游戏中启用 Mod。更新后需要重新启动游戏。

**所选卡牌没有出现在起手手牌里？**

它已加入牌组，会随正常洗牌和抽牌出现。

**靶场会影响正常冒险吗？**

靶场使用独立的临时战斗，不保存本局进度，也不更新正常冒险的战斗进度。

**为什么某些怪物表现不同？**

靶场尽量使用怪物的原版遭遇场景、站位、地图和房间类型，开场只保留所选怪物。死亡召唤和转阶段沿用原版逻辑；仅作为召唤物出现、没有独立开场站位的怪物使用独立靶场场景。依赖开场同伴的机制可能与完整遭遇不同。目前只支持单人训练。

**如何反馈问题？**

请提供游戏版本、所选角色/卡牌/怪物、操作步骤及报错截图。游戏日志中的 `[SpireRange]` 记录有助于定位问题。
